# Reproducing the analysis

This document explains how to regenerate **every figure and table** (main text
and supplementary) from scratch.

## Recommended: run the notebook in VS Code

1. Open the repository folder in **VS Code** (with the Python and Jupyter
   extensions installed).
2. Download `dataset.txt` from the NanoTox repository and place it at
   `data/dataset.txt` (see `data/README.md`).
3. Create and select an environment:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Open `notebooks/00_Run_Full_Pipeline.ipynb`, select the venv kernel, and
   choose **Run All**.

The notebook runs all nine stages in order, saving their figures (300-DPI PNG) to
`results/figures/` and tables (CSV) to `results/`, displaying each one inline, and
finishing with a self-check confirming 483 → 364 → 68. Figure 3, Figure S1b,
Figure S3, and Table S6 come from the five reviewer-requested revision analyses and
are produced by `run_all.py`, not by the notebook.

## Alternative: command line

```bash
cd scripts
python run_all.py
```

## Figures (all 300-DPI, grayscale-safe)

- **Figure 1** — validation gap (k-fold vs LOMO) vs duplicated fraction.
- **Figure 2** — per-seed LOMO MCC per model (MLP instability).
- **Scheme 1** — workflow overview of the benchmark audit and validation (from
  the workflow generator; all values sourced from the stage CSVs, no new computation).
- **Bootstrap forest plot** (`bootstrap_forest.png`) — LOMO MCC with 95% bootstrap
  CIs; a repository visualization of Table 1, not a numbered manuscript figure.
- **Figure S1a** — permutation null distribution of the XGBoost LOMO MCC.
- **Figure S1b** — permutation null distribution of the MLP LOMO MCC (from the
  revision script `permutation_test_mlp.py`; see `REVISION_ANALYSES.md`).
- **Figure S2** — per-oxide held-out performance with n / cytotoxic counts.

Styling is centralized in `scripts/figstyle.py` — restyle everything in one place.


Main-text Tables 1-2 and supplementary Tables S1-S5, S7 and all main/supplementary
figures are regenerated by the nine pipeline stages from `data/dataset.txt`.
Two supplementary tables come from the reviewer-requested revision scripts documented
in `REVISION_ANALYSES.md`, not the core pipeline: **Table S6** (hyperparameter
sensitivity) from `hyperparameter_sensitivity.py`, and the MLP permutation figure
(Figure S1b) from `permutation_test_mlp.py`. **Table S8** (software environment) is a
static record of package versions, not a computed output. Table S1's duplicated-fraction
rows come from the controlled duplicate-injection experiment in `leakage_curve.py`
(stage 2), which injects exact duplicates at known rates purely to demonstrate the
leakage mechanism. Scheme 1 (the workflow overview) is produced from the values
already computed by the stages above; it introduces no new numbers.
