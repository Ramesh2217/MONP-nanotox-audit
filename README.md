# MONP-Benchmark-Audit

Reproducibility audit of a publicly available metal-oxide nanoparticle (MONP)
cytotoxicity benchmark. This repository contains the analysis code accompanying
the manuscript:

> *Apparent machine-learning performance in a metal-oxide nanoparticle
> cytotoxicity benchmark is driven by validation strategy and duplicate records.*
> Avuguddi, R. B., Miditana, S. R., Bobburi, N., Korlam, S., & Theertham, G.

The study examines how duplicate records and the choice of validation strategy
affect apparent model performance on the NanoTox benchmark, and whether
machine-learning models offer any advantage over a simple dose-based baseline
when entire oxide classes are held out (leave-one-oxide-out, LOMO).

## What this repository contains

This repository provides the **analysis code only**. The benchmark dataset is
**not redistributed here** and must be obtained directly from the original
NanoTox repository (see [`data/README.md`](data/README.md)).


## Data

The analysis uses the NanoTox benchmark (`dataset.txt`) released by Subramanian
and Palaniappan (2021), available from the NanoTox GitHub repository:
https://github.com/NanoTox/ToxicityModel (MIT License).

Download `dataset.txt` and place it at `data/dataset.txt` before running any
script or notebook. See [`data/README.md`](data/README.md) for details.

## Reproducing the analysis

1. Obtain the dataset (see above) and place it at `data/dataset.txt`.
2. Create an environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Run the **entire pipeline** with one command (recommended):
   ```bash
   cd scripts
   python run_all.py
   ```
   This runs all nine stages in order, writes 300-DPI grayscale-safe figures to
   `results/figures/`, writes all result tables to `results/`, and finishes with
   a self-check confirming the run reproduces the reported dataset composition
   (483 → 364 unique, 68 cytotoxic).

   Alternatively, run the master notebook `notebooks/00_Run_Full_Pipeline.ipynb`,
   or the individual scripts/notebooks for a single analysis:
   ```bash
   python scripts/duplicate_audit.py
   python scripts/leakage_curve.py        # writes Figure 1
   python scripts/lomo_validation.py
   python scripts/baseline_models.py
   python scripts/bootstrap_ci.py
   python scripts/permutation_test.py
   python scripts/seed_stability.py        # writes Figure 2
   python scripts/feature_decomposition.py # writes Table S4
   python scripts/per_oxide_folds.py       # writes Figure S2
   ```

## Figures

Publication-grade figures (300 DPI, journal-neutral, grayscale-safe) are written
to `results/figures/`:

- `Figure1_leakage_curve.png` — leakage gap vs duplicated fraction, with OLS trend.
- `Figure2_seed_stability.png` — per-seed LOMO MCC for each model (shows MLP
  instability vs the seed-stable behaviour of the other classifiers).

The copies shipped in this repository were generated by the authors' run and are
overwritten when you re-run the pipeline.

## Analysis overview

| Step | Script | Notebook | Purpose |
|------|--------|----------|---------|
| — | `run_all.py`          | `00_Run_Full_Pipeline.ipynb` | Run all stages end-to-end + self-check |
| 1 | `duplicate_audit.py`  | `01_Data_Audit.ipynb`        | Audit and remove exact duplicate records (483 → 364) |
| 2 | `leakage_curve.py`    | `02_LOMO_Validation.ipynb`   | Leakage gap vs duplication fraction (**Figure 1**) |
| 3 | `lomo_validation.py`  | `02_LOMO_Validation.ipynb`   | Leave-one-oxide-out evaluation of the classifiers |
| 4 | `baseline_models.py`  | `02_LOMO_Validation.ipynb`   | Single-variable dose-threshold baseline under LOMO |
| 5 | `bootstrap_ci.py`     | `03_Bootstrap_CI.ipynb`      | Bootstrap 95% confidence intervals for MCC |
| 6 | `permutation_test.py` | `04_Permutation_Test.ipynb`  | Permutation test of LOMO performance against the null |
| 7 | `seed_stability.py`   | `05_Seed_Stability.ipynb`    | Stability across random seeds (**Figure 2**, Table S2) |
| 8 | `feature_decomposition.py` | `00_Run_Full_Pipeline.ipynb` | Full / dose-only / no-dose descriptor sets under LOMO (Table S4) |
| 9 | `per_oxide_folds.py`  | `00_Run_Full_Pipeline.ipynb` | Per-oxide held-out performance with n / cytotoxic counts (Table S3, **Figure S2**) |

Beyond these nine core stages, `run_all.py` also runs five reviewer-requested
revision analyses (documented in [`REVISION_ANALYSES.md`](REVISION_ANALYSES.md)),
for 14 steps in total.

`common.py` holds the shared data path, descriptor set, and deduplication rule;
`figstyle.py` holds the publication-grade, grayscale-safe figure style.

## Reproducibility settings

A fixed random seed (42) is used for the primary analysis; eight seeds
{0, 1, 2, 3, 7, 13, 42, 99} are used for the stability assessment. Software
versions are pinned in `requirements.txt`.
